# 官方 1.0.2 手柄支持检查

检查日期：2026-10-28。对象为用户本地官方 WuwaTappo.exe 1.0.2，SHA-256：099b62be14efe2cc99bb0ad3d37860488c42fb0f4e6282b5687e6335ab178573。

## 已确认的代码行为

- PE 导入表包含 xinput1_4.dll / XInputGetState，原生包中包含 src\gamepad_input.rs 和 gamepad-button-press 事件。
- 原生观察线程按 XInput 设备槽位 0–3 查询状态。能识别方向键、Start/Back、左右摇杆按下（L3/R3）、肩键、A/B/X/Y 和左右扳机越过阈值的按下。
- 本次跟踪的轮询路径只使用数字按钮位及左右扳机值；通过当前状态与上一状态差分报告新按下位。未见同一路径报告松开事件、摇杆坐标或连续扳机值。
- 前端 index-CAndEweT.js 已监听 gamepad-button-press，但当前处理器不读取具体按钮，仅增加本地点击数并触发桌宠敲击。
- 官方现有事件不足以支持完整状态显示。Helper 1.0.2.5 已新增独立 SDL3 原生采集层和手柄显示、校准、TXT 录制，详见[手柄使用说明](手柄使用说明.md)；原程序的点击计数路径保留，未进行实体手柄实测。

## 映射功能的可行范围

| 手柄类型 | 可行路径 | 限制 |
| --- | --- | --- |
| Xbox 与 XInput 兼容设备 | 复用官方 XInput 基础，补充完整状态及松开事件 | 主界面需增加按键、扳机和摇杆显示；录制需新增手柄记录类型 |
| PS4 DualShock 4、PS5 DualSense | 增加原生 SDL/HID 兼容层；转换为 XInput 的设备可先走现有通道 | 不能只切换按钮文字就宣称 PS 原生直连可用；USB、蓝牙和转译设备需要分别验证 |
| 其他手柄的 XInput 模式 | 按 XInput 标准布局归一化 | 品牌名称不足以判断接口模式 |
| DirectInput、Switch 和其他 HID 手柄 | 使用 SDL 游戏手柄层及设备映射配置 | 按型号补充映射和校准，不承诺未知设备全部自动兼容 |

完整实现应包括：设备识别与热插拔、Xbox/PS/通用外观选择、按下/松开、双摇杆二维位置与死区、左右扳机进度、显式开始/结束录制及 TXT 导出、多设备去重。这里的映射指展示和录制；修改游戏内键位是另外的需求。

## 参考资料

- [SDL3：PS4 HID 驱动](https://wiki.libsdl.org/SDL3/SDL_HINT_JOYSTICK_HIDAPI_PS4)、[PS5 HID 驱动](https://wiki.libsdl.org/SDL3/SDL_HINT_JOYSTICK_HIDAPI_PS5)：提供相应设备的原生适配路径。
- [SDL3：增加或修改设备映射](https://wiki.libsdl.org/SDL3/SDL_AddGamepadMapping)：支持按设备配置按钮、轴和方向帽映射。
